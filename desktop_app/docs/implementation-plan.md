# PerlerDrawing Desktop 实施流程

本流程把产品文档中的四个阶段拆成可独立验证的增量. 每一步结束时都保持主分支可构建, 并只实现该步所需的最小边界.

## 1. 桌面基础壳

状态: 已完成.

- Tauri 2 + React + TypeScript strict + Vite.
- 本地设计令牌和响应式启动页.
- `zh-CN` 和 `en-US` 即时切换.
- 浅色, 深色和跟随系统主题.
- 最小 Tauri capability 和生产 CSP.
- Vitest, React Testing Library, ESLint 和 Prettier 基线.

验收: `pnpm lint`, `pnpm typecheck`, `pnpm test`, `pnpm build` 和 `cargo check` 全部通过.

## 2. 编辑器核心模型

状态: 已完成.

- 使用 `Uint16Array` 保存网格, 空格使用保留值.
- 分离文档状态, UI 状态和后台任务状态.
- 建立可逆命令对象和撤销/重做历史.
- 建立色卡 registry, 导入并校验 MARD 221 v1.
- 为占用外接矩形, 几何算法和命令可逆性建立单元测试.

实现约定:

- 空格固定为 `65535`, 有效色卡索引范围为 `0` 到 `65534`.
- 命令执行前先检查所有旧值, 检查失败时不修改任何格子.
- 撤销历史默认最多保留 200 个命令. 每次拖动工具应生成一个命令.
- 偶数格线宽使用方形笔刷, 额外的行和列固定向正坐标方向扩展.
- 内置 MARD 文件是仓库色卡的不可变应用快照, 测试会检查两份 JSON 完全一致.

验收: `pnpm lint`, `pnpm typecheck`, `pnpm test`, `pnpm build`, `cargo fmt -- --check` 和 `cargo check` 全部通过. 当前共有 9 个测试文件和 23 项测试.

## 3. Canvas 编辑器

状态: 已完成.

- 分层 Canvas 2D 渲染网格, 坐标, 分块线和板子边界.
- 实现画笔, 橡皮擦, 吸管, 填充, 直线, 矩形和圆或椭圆.
- 实现平移, 缩放, 适应窗口和格坐标命中测试.
- 补充键盘操作, 焦点管理和 reduced motion.

实现约定:

- 新建空白图纸时显式填写画布, 板子和分块参数. 当前 UI 安全上限为 500 x 500, 默认色卡为内置 MARD 221 v1.
- 基础网格与拼豆使用底层 Canvas, 光标和工具预览使用独立交互 Canvas. React 不为每个格子创建 DOM 节点.
- UI 坐标从 1 开始显示, 文档存储和几何算法继续使用从 0 开始的行列索引.
- 画笔和橡皮擦拖动通过 Bresenham 路径补齐格子, 整段手势提交为一个命令. 几何工具只在松开时提交预览结果.
- 平移保持 1:1 指针响应且不增加惯性. 缩放围绕鼠标锚点进行, 格子显示范围为 1 到 72 CSS 像素.
- 鼠标中键或空格加拖动可临时平移. `B`, `E`, `I`, `F`, `L`, `R`, `O`, `H` 切换工具, `0` 适应窗口, `+` 和 `-` 缩放.

验收: `pnpm lint`, `pnpm typecheck`, `pnpm test` 和 `pnpm build` 全部通过. 当前共有 11 个测试文件和 30 项测试. 已在真实浏览器中检查深浅主题, 中英文, 单格与连续笔画, 单次撤销, 洪泛填充, 矩形工具, 平移和锚点缩放.

## 4. CSV 导入和导出

状态: 已完成.

- 支持仓库矩阵格式和简单矩阵格式.
- 检测 BOM, 逗号和制表符, 严格校验行宽和未知色号.
- 导出 UTF-8 with BOM, 并立即回读执行 round-trip 校验.

实现约定:

- 使用 Papa Parse 处理引号, 转义和单元格内换行, 不使用字符串分割模拟 CSV 解析.
- 仓库格式使用 `row/col` 和从 1 开始的连续行列坐标. 简单矩阵可使用 MARD 色号或与色卡精确相等的 `#RRGGBB`.
- 导入上限为 8 MB 和 500 x 500 格. 行宽, 坐标, UTF-8 和尺寸不合法时终止导入.
- 未知色值按源矩阵的 1-based 坐标列出. 当前版本将其作为错误终止, 不执行近似颜色替换.
- 变换顺序固定为转置, 水平翻转, 垂直翻转, 且只在用户显式勾选后执行.
- CSV 导出来自克隆的文档快照, 默认包含坐标, 使用 UTF-8 BOM 和 CRLF. 保存前立即重新解析并逐格比较尺寸与色号.
- 桌面文件访问使用 Tauri dialog 和 fs 插件. capability 只开放文件选择, 保存, 读取所选文件和写入所选文件所需的命令.

验收: `pnpm lint`, `pnpm typecheck`, `pnpm test`, `pnpm build`, `cargo fmt -- --check` 和 `cargo check` 全部通过. 当前共有 14 个测试文件和 47 项测试. 已在真实浏览器中检查中英文和深浅主题的导入预检与导出对话框, 并通过界面交互覆盖全空 TSV round-trip 边界.

## 5. 图片转换和完整导出

状态: 已完成.

- 抽取 Python 通用算法并建立 JSON Lines sidecar 协议.
- 实现高分辨率母图, 背景分割, 小波结构简化, 预乘 alpha 重采样, 聚类和色卡量化.
- 生成 PNG, inventory, metadata, tiles 和 `.tar.gz`.
- 所有导出物从同一个不可变文档快照生成并经过统一验证器.

实现约定:

- 图片上限为 64 MB 和 3200 万像素. 解码时应用 EXIF 方向, 并尝试把嵌入 ICC 配置转换到 sRGB.
- 自动去背景使用边框颜色的 Lab 聚类和四连通 flood matte. 只有能从图片边界到达的候选背景才会被移除, 内部孤立的相似颜色不会被直接清空. 已有有效 alpha 时优先保留原 alpha.
- 高分辨率母图使用两层 Haar 小波软阈值压制纹理, 再按亮度梯度把强边缘混回. 随后在 Lab 空间聚类合并反光和无意义的小色差. 不把原图通过最近邻或单次缩放直接变成图纸.
- 最终栅格化使用预乘 alpha 的 BOX 面积采样. 网格颜色先聚类为紧凑代表色, 再选择唯一的真实 MARD 子集并逐格映射.
- 随机聚类保存 seed. 对称后处理不会因为基准半边为空而静默删除另一侧结构, 并记录对称轴或中心及逐格校验结果.
- React 只管理参数, 进度和预览. Rust 命令只启动固定 sidecar, 管理应用缓存任务目录和取消进程. 大图片和结果文件通过任务目录传递.
- 完整导出克隆当前文档为不可变快照, 生成带 BOM 的 CSV, 透明与白底预览, 完整坐标图, inventory, metadata, 色卡快照, 分板图和安全相对路径的 `.tar.gz`. 图片来源还会包含去背景后的高分辨率母图.
- 归档使用临时文件生成并在全部验证通过后原子替换目标. 空图纸, 非法色卡索引, 材料数不一致, 预览占用不一致或不安全归档路径都会终止导出.

验收: 9 项 Python 算法和协议测试, 17 个前端测试文件中的 54 项测试全部通过. `pnpm lint`, `pnpm typecheck`, `pnpm test`, `pnpm build`, `pnpm format:check`, `cargo fmt -- --check` 和 `cargo check` 全部通过. 已在真实浏览器中检查中英文, 深浅主题, 图片三栏对比页, 页面切换滚动复位和完整导出弹窗, 浏览器控制台没有应用错误.

## 6. Codex 集成和安装包

状态: 已完成.

- 在隔离临时 Git 仓库中调用用户明确启用的 Codex CLI.
- 验证 JSONL 进度, 取消, 超时和不可信输出.
- 构建 Windows NSIS 和 Arch Linux 软件包.
- 增加可执行的 GitHub Actions 检查与发布流水线.

实现约定:

- Codex 是图片导入页的实验性可选处理器, 默认关闭. 首次启用时明确说明图片任务副本, 写入范围, 模型服务传输和凭据边界.
- Rust 只执行从 `PATH` 解析并规范化后的 `codex` 原生可执行文件. 启动前探测 `codex exec --help`, 要求图片附件, JSONL, ephemeral, user-config 隔离, `workspace-write`, 工作目录和最终消息参数均可用.
- 每个任务只复制输入图片, MARD 色卡, 参数和仓库 `AGENTS.md` 到应用缓存中的独立 Git 仓库. 不读取或复制 `~/.codex/auth.json`, 不提供 `danger-full-access`.
- Codex 只生成最大 16 KB 的 `output/plan.json`. Rust 拒绝符号链接, 目录逃逸, 多余字段, 非法枚举和越界参数. TypeScript 在应用参数前再次校验, 最终图纸仍由本地小波, 聚类, 去背景和 MARD 流水线生成.
- JSONL 单事件上限 1 MB, 单任务上限 10000 个事件, 默认超时 300 秒. UI 显示最近事件类型, 事件数, 运行时间和取消按钮. 失败时保留用户参数并回退到本地处理器.
- PyInstaller 6.22.2 在各目标平台原生构建单文件 sidecar. 选择 `onefile` 是为了符合 Tauri external binary 的单可执行文件部署边界, 避免 `onedir` 的动态库目录在 NSIS 和 pacman 布局之间产生不同解析规则.
- Windows 使用 Tauri NSIS, 简体中文和英文安装界面, 当前用户安装. Arch 使用 `PKGBUILD` 把 Tauri binary, sidecar, desktop entry 和图标组装为 `.pkg.tar.zst`.
- GitHub Actions 在 PR 和 `main` 运行完整质量检查. `workflow_dispatch` 构建测试安装包, `app-v*` 标签在 Windows 和 Arch 环境分别构建后发布安装包与 SHA-256 清单.

验收: 3 项 Rust Codex 边界测试, 3 项前端 Codex 参数与首次授权测试和现有全部测试通过. PyInstaller 原生 sidecar 已完成协议冒烟测试. 本机 Arch 包已由 `makepkg` 生成并通过 `pacman -Qp` 和 `pacman -Qlp` 检查. Windows NSIS 由 `windows-latest` 发布 job 原生构建, 避免跨平台生成不可验证的 Windows sidecar.

## 7. 高级编辑能力

状态: 已完成.

- 选区, 移动, 复制, 旋转, 镜像和对称绘制.
- 掩码修正, 分板打印, PDF 和版本比较.
- 300 x 300 及更大网格的性能分析和脏矩形优化.

实现约定:

- 选区属于编辑器 UI 状态, 不写入图纸网格. 框选, 拖动和方向键移动, 复制粘贴, 顺时针旋转, 水平或垂直镜像均在边界检查后生成单个可撤销命令. 粘贴不会静默裁掉超出画布的格子.
- 对称绘制约束保存在文档中并进入撤销历史. 竖直轴, 水平轴和中心对称支持显式轴或中心, 默认使用画布几何中心. 画笔, 擦除, 填充和几何工具在命令写入前扩展对应格.
- 背景掩码可继续用画笔和橡皮逐格补画或擦除. 批量修正只删除八邻域完全孤立的单格, 或填补四面均被占用的单格孔洞. 两种操作可限定在选区且均可撤销, 不执行不透明的激进清理.
- 版本比较严格按当前色卡解析参考 CSV 或 TSV, 分别统计当前新增, 当前删除和颜色变化. 差异只绘制在交互叠层, 不修改文档.
- ReportLab 从不可变文档快照生成 A4 分页 PDF, 每块实体板一页, 保留全局行列坐标和 MARD 色号. 100% 打印使用 5.08 mm 格距. 独立 PDF 通过临时文件原子替换, 完整 `.tar.gz` 也包含同一分板 PDF.
- 画布分为静态背景, 拼豆, 网格辅助线和交互层. 视口或主题变化时完整重绘; 普通文档命令只比较紧凑数组并重绘实际变化的最小矩形. 300 x 300 网格测试验证单格或小区域修改不会退化为整画布绘制, React 仍不创建逐格 DOM.

验收: 25 个前端测试文件中的 71 项测试, 11 项 Python sidecar 测试和 3 项 Rust 测试全部通过. TypeScript 类型检查, ESLint, Prettier, Vite 生产构建, Cargo 格式和编译检查均通过. 分页 PDF 已使用 pypdf 和 Poppler 检查 A4 页数和元数据, 并在 29 x 29 实体板页面上检查坐标, 色号, 边界和 5.08 mm 格距的渲染清晰度. PyInstaller 单文件 sidecar 已实际执行 PDF 任务并通过协议和页数检查.
