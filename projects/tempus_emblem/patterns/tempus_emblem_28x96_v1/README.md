# Tempus emblem v1 - 28 x 96 占用范围

- 图纸网格: 100 x 100.
- 拼板: 1 块 100 x 100.
- 实际主体范围: 28 x 96 格.
- 主体位置: 第 3-98 行, 第 37-64 列.
- MARD 色数: 11.
- 拼豆总数: 1570.
